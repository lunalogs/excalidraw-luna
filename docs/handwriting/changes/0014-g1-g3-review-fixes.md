## 本批解决的问题

### G1 / F4 / R3 — 闭合轮廓只测局部墨迹
- `getRepresentativeStrokeWidth` 弦测量改为**近侧区间**：法线与轮廓的交点只取 `s>0` 最小与 `s<0` 最大（中心线采样点两侧的最近轮廓），不再全局 min/max 跨内部空洞与远侧笔画。圆/椭圆/闭合矩形的法线原先会同时穿过近侧环墨与远侧环墨，把直径（208px@r100）当成墨迹厚度。
- 线段交点公式改为规范形式：`s = ((A−P)×E)/(n×E)`，`t = ((A−P)×n)/(n×E)`（原 `−denom` 版本与镜像方程自洽、物理命中集相同，但易误读，按复核意见统一）。
- 新增 4 项独立界限测试（圆 r=30/60/100、椭圆、闭合矩形、扁笔圆、变压圆），非零 pressureAmount 下圆代表线宽稳定在名义 8.5px 的 7–11px 区间；Codex 的宽度探针复测：r=30/60/100 分别返回 8.51/8.50/8.50（修复前 68.9/128.8/208.7）。
- 函数头注释已同步为实际的"中位弦宽"算法（删除过期的"平均半径再除 4.25"说明）。

### G2 / F3 / R5 — 真实写入失败迁移 + 恢复显式合并
- 不再依赖预探测判断最终结果：探测只决定挂载起点；**实际保存失败时**（persist 捕获异常后）面板把整个当前库迁移进共享会话库（重名加后缀、id 重新生成）并切换到会话库显示"仅本次会话"提示——面板关闭重开预设仍在。
- 恢复规则（显式、不静默丢失）：`createPanelPresetLibrary` 在存储可写时，把会话库中来自此前故障期的预设**合并进**新存储库（重名时会话项加后缀——存储数据赢得名称；id 重新生成；合并成功项从会话库移除并持久化），合并失败项保留在会话库。旧的可读预设自然保留在存储库中。
- 0013 独立重放（探测放行、真实写入抛配额）**修复前失败 → 现通过**；新增恢复合并 UI 测试（故障期存"Recovered session pen" → 恢复后重开 → 出现在选项且已写入 localStorage）。

### G3 / F3 / R5 — 部分坏记录先备份再允许覆盖
- `load()` 在逐条验证丢弃任何记录时（droppedPresetCount > 0）同样先 `backupCorruptRaw`：下一次保存覆盖原 key 前，含坏条目的原始 payload 已复制到 `<key>.corrupt-backup`（不覆盖既有备份；备份失败静默——UI 不声称原始数据已安全）。
- 新增测试：合法顶层 + 一条不完整预设 → 打开 → 保存新预设 → 备份键存在且等于原始 JSON。0013 独立断言原样通过。

### F6 文档措辞
- 注释与记录措辞修正：1024 是**弧长采样目标**（自适应步长），零长度样本逐个保留，复杂度 O(maxSamples) + O(input)，不是一切输入的严格总上限。
