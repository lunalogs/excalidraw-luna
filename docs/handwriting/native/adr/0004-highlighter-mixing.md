# ADR-0004：荧光笔叠色（原型验证项，不预设结论）

## 问题

两条重叠荧光笔在 PKCanvasView 原生渲染 vs 网页逐笔 PNG 拼接的混色可能不一致（alpha 叠加顺序/色彩空间）。

## 决定

- P0 原型生成"两条交叉荧光笔"fixture：原生截图作为基准；网页拼接渲染作对照；输出差异图与数值（逐像素 RMSE）。
- 若偏差可见：优先**分块/分组缓存 + 对象映射**（把空间重叠的笔迹合成渲染组），不谎称无损；不可接受时记录为已知限制并回退"单组渲染"策略。
- 不为了叠色一致而改原始 drawing 字节。
