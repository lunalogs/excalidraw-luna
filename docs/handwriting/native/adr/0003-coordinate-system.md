# ADR-0003：统一坐标系

## 决定

- **文档坐标 = 世界点（scene point）**，与 Excalidraw 一致：y 向下、CSS px 为单位、原点画布置顶左上。
- UIKit point ↔ CSS px：同数值（PT 与 CSS px 在 UI 尺度等价），DPR 只影响栅格采样，不进文档坐标。
- 原生墨迹资源保存**局部几何**（PKDrawing 原始坐标），`worldTransform`（等比缩放+平移的 6 项仿射）在 manifest 中只应用一次；iPad 重建编辑画布时应用矩阵，原生编辑提交新资源时事务性归一变换，防止二次打开重复缩放（SPEC 3.2）。
- 旋转屏幕/分屏只改视口，不改文档坐标；保存坐标不依赖设备尺寸。

## 待验证

P0 原型：三笔在 0.25x/1x/4x 下网页预览与原生位置一致（坐标断言不共用被测变换函数）。
