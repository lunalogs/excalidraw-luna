## 4. W02–W04：格式、资源与渲染的生产要求

### 文件契约与恢复能力

- 提交可阅读schema、TS/Swift模型、版本协商与验证规则；documentId在同文档保存中稳定，revision按成功事务推进，不每次随机建新文档。另存副本的身份语义明确。
- 明确整数版本/顺序、正等比矩阵、可见bounds、objectId/assetId/version、split/replacement图（支持一对多）、能力列表和资源哈希语义。校验引用存在、资源唯一、大小/内容哈希一致，拒绝非法矩阵和无效图关系。
- 路径只允许规范化容器相对路径；检查正反斜杠、绝对/盘符/URL、..、空/NUL、规范化后重名、symlink以及重复ZIP entry，禁止解压逃逸和网络取资源。
- 写VALIDATION_LIMITS：压缩体积、单条目/总解压量、条目数、manifest、图像解码尺寸、命中点数和坐标/缩放范围；预算应在解压/分配中执行，不能先全读再检查。数值按fixture实测给理由，别只设无限大避免失败。
- 未知主版本拒绝写入；原生资源不支持解码时保留完整源与可用预览并明确只读/受限状态，不能变空或静默降级。可保留的扩展字段与opaque资源双端往返不丢。
- 导入先读取/校验/准备完整候选文档，成功后一次替换；异步期间用户另开文档则旧结果失效。失败保留旧文档、选择和历史。
- 资源库由哈希/版本引用，撤销、恢复草稿、保存进行中仍引用的资源不可提前GC；删除撤销恢复完整字节，预览可重建但drawing不可当缓存清理。
- 原子保存临时写全、校验、协调替换；同时保存串行化或版本化，旧请求不能覆盖新revision。故障注入覆盖写到一半/替换失败/权限丢失，原文件字节保持。

### 预览、命中、混色

- 全部fixture来自公开API合成或非私人测试笔迹，附生成器/SDK/OS/许可/sha256。包括重复笔迹、不同墨水、透明度、交叉荧光笔、mask洞、长线、密集笔迹及嵌入图片。
- 生成scene坐标下可用的局部预览/可见命中几何，验证mask洞不命中、边缘容差按屏幕距离换算；记录近似误差及0.25x/1x/4x下行为。
- 视觉对照必须同顺序、同像素尺寸、同色彩/透明背景；保存原生图、真实网页截图、差分图，报告有效墨迹区域与交叉区域指标，不用大面积空白稀释整图RMSE。
- 分组/分块缓存不能剥夺逐笔选择/删除；网页删/移某笔时，旧合成块不能残留幽灵笔画。网页无法重生成原生混色时给出可执行降级和误差证据，不把陈旧缓存继续当正确图。无法达到产品要求则列真正阻塞，不能宣称像素无损。
- 预览异步生成，结果带资源版本/会话戳；过期结果丢弃，保存等待必要资源完成。主线程不随每个采样点遍历/序列化全页。

## 5. W05–W06：桌面完整整理

- 建立有类型的ink对象适配器；渲染、bounds、命中、选择、历史、文件序列化都接同一模型，不用不可编辑的全页图片替代。
- 套索按SPEC选完整可见笔画；跨边线与被包含区域、擦除洞、锁定、空选、混合对象均有正负用例。
- 混合平移/等比缩放围绕固定锚点；宽度同比，文字与绑定箭头沿用既有约束；不能只改图片预览而不改worldTransform。不支持的旋转/镜像/非等比控件对含ink选择禁用并说明，不能悄悄拉伸。
- 橡皮一次扫过多笔一次历史，重复命中去重；pointercancel回滚，撤销/重做还原对象ID、顺序和资源引用。
- 审计复制粘贴/复制对象、分组、锁定、清空场景、删除、导出、工具切换等现有入口：支持的给新对象新ID且保留资源，不支持的显式禁用，不能借这些入口丢drawing。混合选择操作有一致反馈。
- 电脑全部只做完整对象整理；不要额外开发桌面压感重写或局部切笔。原生绘制源不因网页操作重新编码。
